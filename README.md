# Digital Security — Learn, Explore & Protect

Project React + Vite yang disiapkan dari file TSX Gemini Canvas.

## Menjalankan secara lokal
1. Install Node.js versi LTS.
2. Buka terminal di folder project.
3. Jalankan `npm install`.
4. Jalankan `npm run dev`.

## Build untuk deploy
Jalankan `npm run build`. Hasil website siap deploy berada di folder `dist`.

## Deploy Netlify
Upload folder `dist` ke Netlify melalui fitur deploy manual / drag-and-drop.
